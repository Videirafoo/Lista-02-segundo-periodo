# Project Workflow — Lista de Algoritmos

## Perfil
Exercícios acadêmicos — **processo mínimo**.

## Fluxo
Enunciado → entender entradas/saídas → algoritmo → implementação → testes → revisão → commit.

## Regras
- Resolver primeiro da forma mais simples e correta.
- Usar apenas conceitos compatíveis com o conteúdo estudado, salvo quando a tarefa pedir algo diferente.
- Nomes claros e lógica legível.
- Evitar bibliotecas e abstrações desnecessárias.
- Testar pelo menos: caso normal, caso limite e um caso alternativo relevante.
- Quando houver erro, identificar a causa antes de reescrever a solução.
- Um exercício pode ser tratado como uma tarefa independente.

## Checklist por exercício
1. Entendi o enunciado.
2. Defini exemplo de entrada.
3. Defini resultado esperado.
4. Implementei.
5. Executei e comparei o resultado.
6. Revisei legibilidade.
7. Corrigi antes de avançar.
