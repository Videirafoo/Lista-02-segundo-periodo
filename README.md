# Lista Python 02

Repositório acadêmico com exercícios de **Linguagem de Programação em Python**, desenvolvido durante o curso de Engenharia de Software.

## Conteúdo

O projeto reúne **20 exercícios** de manipulação de listas e lógica de programação.

A organização está dividida em duas pastas:

```text
LIST/   -> exercícios 1 a 10
LIST2/  -> exercícios 11 a 20
Main.py -> execução sequencial dos exercícios
```

## Conceitos praticados

- criação e acesso a listas;
- percursos com `for`;
- busca de elementos;
- soma, média, maior e menor valor;
- inserção e remoção;
- compreensão de listas;
- manipulação de dados;
- funções em Python;
- aplicações simples com listas.

## Como executar

Para executar o conjunto completo:

```bash
python Main.py
```

Também é possível executar cada exercício individualmente, por exemplo:

```bash
python LIST/Exerc1.py
```
