# Lista 02 — Listas e Manipulação de Dados em Python

Repositório acadêmico com **20 exercícios de Linguagem de Programação em Python**, com foco em listas, funções e manipulação de dados.

**Nível:** iniciante → intermediário  
**Objetivo:** consolidar o uso de listas e começar a organizar soluções em funções reutilizáveis.

## Estrutura

```text
LIST/   -> exercícios 1 a 10
LIST2/  -> exercícios 11 a 20
Main.py -> execução sequencial dos exercícios
```

## Conceitos praticados

- criação e acesso a listas;
- percursos com `for`;
- busca de elementos;
- soma, média, maior e menor valor;
- inserção e remoção;
- compreensão de listas;
- manipulação de dados;
- funções em Python;
- aplicações simples com listas.

## Como executar

Todos os exercícios:

```bash
python Main.py
```

Um exercício específico:

```bash
python LIST/Exerc1.py
```

## Como estudar

1. tente resolver cada problema antes de executar a solução;
2. teste listas vazias, valores repetidos e números negativos quando fizer sentido;
3. identifique o que poderia virar uma função reutilizável;
4. compare soluções mais simples com soluções mais legíveis;
5. anote o que mudou em relação à Lista 01.

## Desafio extra

Escolha três exercícios e adapte para receber os dados por função, em vez de depender diretamente de `input()`.
